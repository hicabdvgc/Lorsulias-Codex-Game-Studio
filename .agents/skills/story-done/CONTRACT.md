# $story-done handoff contract

Adapted from Claude Code Game Studios to the installed Codex workflow.

## Prerequisites
Identified implemented story, required output/evidence and applicable current governance/reviews.
Read the linked execution-and-evidence and progression guidance as applicable. A file path alone does not
prove the prerequisite outcome. Unknown or conflicting inputs block dependent conclusions/writes.

## Outputs and permitted changes
Completion assessment; within closure authorization, one Complete header/Completion Notes and matching derived status.
Existing explicit task authorization carries through bounded writes. Reviews are read-only by default;
requested report saves do not confer approval. Re-read shared records and preserve concurrent changes.

## Guarantees and limitations
All required criteria and reviews must pass before closure. Advisory notes do not waive unavailable checks. Revalidation preserves completion date.
Accepted ADRs, durable TRs and integer CONTROL apply where governing; justified N/A cannot hide missing
required decisions. Preserve actual story authority, output identities and required independent review.
Verify promised saves; record partial state and the dependent consumer if a save fails. Native dispatch,
engine execution and human assessment must be reported only when they actually occur.
