# Optional Local Instruction Override

Codex can use AGENTS.override.md instead of AGENTS.md at the same directory level.
An override can therefore hide shared instructions. If creating one for a genuine
local need, explicitly retain/reference the shared studio guidance you still need.
The file is gitignored. This template is an authoring aid; it is not auto-loaded.

```markdown
# Local Studio Instructions

Read the shared AGENTS.md explicitly and retain its workflow requirements.

## Local differences
[State only the actual local preference or environment fact being supplied.]
```

Do not copy this explanatory file verbatim as an active override. No specific
editor, engine, permission mode, compaction command, or new-chat behavior is
required by this template. Remove an override when its temporary purpose ends.
