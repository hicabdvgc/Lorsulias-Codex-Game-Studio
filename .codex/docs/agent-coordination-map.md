# Responsibility and Coordination Map

| Activity | Responsible executor | Decision or handoff |
|---|---|---|
| Concept authorship and reference-game play | Human developer | Supplies CONCEPT and actual experience |
| Design/research/resource/tool work | Assigned person or agent with relevant capability | Returns the requested result and unresolved decisions |
| Scope, scheduling, and dependencies | Current coordinator; producer persona when useful and available | Presents evidence and options for user decisions |
| Technical or creative conflict | Relevant available experts and coordinator | User settles unresolved product/strategic tradeoffs |
| Required independent review | A reviewer independent of the author for that check | Returns findings for the same input revision |
| Human usability and playtesting | Actual intended users/players | Supplies observations; AI may organize the evidence |

The current agent can perform responsibilities that fit its capabilities and task
authorization. Self-review must be identified as such and does not satisfy a
requirement for independent review. Missing expertise/evidence leaves the affected
check unassessed. The producer coordinates; it does not supply every domain verdict.

Follow [coordination-rules.md](coordination-rules.md) for task boundaries and
[review-workflow.md](review-workflow.md) for reviews. See the installed roster for the producer, general design/technical roles and
Godot/Unity/Unreal specialists, visual, audio, UX, level, narrative, economy,
localization, QA, tooling, implementation, performance, security, DevOps, release,
community, analytics, and live-operations expertise. Release work retains
candidate-specific evidence and authorized external actions.
