# Quick Start

Open the studio as the intended project root and read AGENTS.md. Check setup-requirements.md for the
actual Bash/Python/parser prerequisites and client hook-loading limits. Do not alter personal runtime
settings or select an engine merely to orient the studio. Live choices belong in docs/technical-preferences.md.

Use $start with a new or returning task, $help for the next relevant activity, $adopt for an existing
project's interface migration plan, $onboard for a role/area, or $studio-status for current declared
section and recovery observations. Follow workflow-catalog.yaml, including developer authorship and
human play/evaluation. Optional review breadth cannot waive required independent/human evidence.

Keep an authorized bounded checkpoint using templates/session-state.md when work spans sessions.
See context-management.md for parser, lifecycle and explicit rotation behavior. For release work read
release-and-operations.md: actual candidate evidence and corresponding delivery/publication authority
are required. No game or live service is installed by this studio skeleton.
