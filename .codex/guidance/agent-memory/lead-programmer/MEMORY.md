# Lead Programmer — Repository Guidance

This is checked-in role guidance, not automatic memory or a record of work done.
Read it when a lead-programmer task needs the studio conventions.

- Skill packages live under `.agents/skills/`; persona definitions live under
  `.codex/agents/`. Apply `.codex/docs/skill-authoring.md` and installed skill guidance.
- Live project choices are in `docs/technical-preferences.md`; the `.codex/docs/`
  counterpart is a template. Do not copy game configuration into shared personas.
- Read applicable full BREAKDOWN, GDDs, FRAMEWORK, accepted ADRs and scoped CONTROL.
  Preserve integer CONTROL revisions and stable TR identifiers.
- References are versioned evidence, not a selected or installed game engine.
- Role guidance does not authorize delegation, installations, commits, or messaging.
  Follow the current task and available runtime capabilities.
