# Skill Test Spec: $ux-design

## Skill Summary

Exercise `.agents/skills/ux-design/SKILL.md` and its listed continuation with isolated fixtures.
Retain useful source interfaces while testing the adapted resource and evidence contracts.

## Static assertions

- Frontmatter name/description and UI metadata parse and match the installed identity.
- Retained references resolve or explicitly identify future/manual inputs.
- Output paths, modes and statuses agree with actual consumers and templates.
- Preserve bounded authorization, concurrent edits, required independent review and human evidence.

## Test cases

### Case 1: Named screen

**Request / fixture:** Author a synchronous keyboard-only pattern-selection screen from supplied GDD/FRAMEWORK and accessibility choices.

**Expected outcome:** Save design/ux/[safe-slug].md with relevant interactions, ownership and evaluation; no invented loading, gamepad, event-only architecture or telemetry.

### Case 2: HUD and patterns

**Request / fixture:** Author a puzzle HUD and a shared Tab Bar pattern, then retrofit one existing field.

**Expected outcome:** Use reserved output paths and current template needs; actual contexts and selected controls only; preserve unrelated content.

### Case 3: Missing decisions

**Request / fixture:** Required input configuration is unset or a shared pattern reference is unwritten.

**Expected outcome:** Identify the dependent gap, clarify the needed choice, and leave completeness unassessed; no automatic session state.

### Case 4: Path and reuse

**Request / fixture:** Give no argument, traversal input, short substantive sections and a complete local interaction.

**Expected outcome:** Ask for target when absent, reject invalid paths, retain real content, and allow fully specified local interactions.

## Evidence and grading

Record raw fixture inputs, request, actual response/artifacts, method and observed
result. Static reading, guided current-agent exercises, script execution and native
runtime dispatch are separate evidence. A fixture or expected answer alone is not
execution. Inspect useful output and failed prerequisites; rerun affected cases after
correction. Apply the shared rubric without arbitrary section or step counts.

## Regression assertion

Optional delegation requires current authorization; installed capability does not grant permission or replace required independent review.
