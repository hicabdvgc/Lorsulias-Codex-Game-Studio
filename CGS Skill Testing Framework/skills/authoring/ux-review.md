# Skill Test Spec: $ux-review

## Skill Summary

Exercise `.agents/skills/ux-review/SKILL.md` and its listed continuation with isolated fixtures.
Retain useful source interfaces while testing the adapted resource and evidence contracts.

## Static assertions

- Frontmatter name/description and UI metadata parse and match the installed identity.
- Retained references resolve or explicitly identify future/manual inputs.
- Output paths, modes and statuses agree with actual consumers and templates.
- Preserve bounded authorization, concurrent edits, required independent review and human evidence.

## Test cases

### Case 1: Applicable design

**Request / fixture:** Review the synchronous keyboard-only screen and a matching persisted pattern.

**Expected outcome:** Assess relevant behavior with current templates and project commitments; APPROVED is limited to the evidenced design scope.

### Case 2: Missing evidence

**Request / fixture:** Repeat with unset authoritative inputs, a missing shared pattern or required human/independent evaluation.

**Expected outcome:** NOT ASSESSED prevents APPROVED, with locations and affected conclusions; known design blockers still retain their revision verdict.

### Case 3: Routing and saves

**Request / fixture:** Use all/hud/patterns and a supplied file, including unrelated Markdown; request a bounded report save separately.

**Expected outcome:** Route supported types, list unsupported files, write nothing by default, save only requested report without changing design status.

## Evidence and grading

Record raw fixture inputs, request, actual response/artifacts, method and observed
result. Static reading, guided current-agent exercises, script execution and native
runtime dispatch are separate evidence. A fixture or expected answer alone is not
execution. Inspect useful output and failed prerequisites; rerun affected cases after
correction. Apply the shared rubric without arbitrary section or step counts.

## Regression assertion

The actual reviewer and independence are recorded. Installed team-ui preserves review conclusions; optional delegation requires authorization.
