# Skill Test Spec: $review-all-gdds

## Skill Summary

Exercise `.agents/skills/review-all-gdds/SKILL.md` and its listed continuation with isolated fixtures.
Retain useful source interfaces while testing the adapted resource and evidence contracts.

## Static assertions

- Frontmatter name/description and UI metadata parse and match the installed identity.
- Retained references resolve or explicitly identify future/manual inputs.
- Output paths, modes and statuses agree with actual consumers and templates.
- Preserve bounded authorization, concurrent edits, required independent review and human evidence.

## Test cases

### Case 1: Early consistency

**Request / fixture:** Review two connected puzzle GDDs without future resource schemas, using consistency focus.

**Expected outcome:** Read selected systems/dependencies, assess early scope without schema prerequisite; no default writes.

### Case 2: Framework/resource integration

**Request / fixture:** Trace adding a key type and modifying capacity through inventory and puzzle GDDs; consumer expects weight while TYPE_TEMP defines count only.

**Expected outcome:** Name the integration contradiction and affected producer/consumer; later resource review reads actual contracts and does not pass from file presence.

### Case 3: Modes and evidence

**Request / fixture:** Exercise full/design-theory/since-last-review with absent baseline, missing mapped GDD and unavailable independent/human evidence.

**Expected outcome:** Preserve focus boundaries, fall back to full explicitly, retain missing targets and return NOT ASSESSED for incomplete required coverage while retaining demonstrated FAIL.

### Case 4: Save and handoff

**Request / fixture:** Explicitly request a report save after a scoped review.

**Expected outcome:** Write only design/gdd/gdd-cross-review-[date].md, verify it, preserve statuses and describe actual architecture/vertical-slice prerequisites.

## Evidence and grading

Record raw fixture inputs, request, actual response/artifacts, method and observed
result. Static reading, guided current-agent exercises, script execution and native
runtime dispatch are separate evidence. A fixture or expected answer alone is not
execution. Inspect useful output and failed prerequisites; rerun affected cases after
correction. Apply the shared rubric without arbitrary section or step counts.

## Regression assertion

Existing bounded save authorization carries through report creation without a repeated prompt; required review evidence remains independent of the save.
