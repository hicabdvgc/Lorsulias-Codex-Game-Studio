# Skill Test Spec: $team-narrative

## Skill Summary

Exercise `.agents/skills/team-narrative/SKILL.md` and its listed continuation with isolated fixtures.
Retain useful source interfaces while testing the adapted resource and evidence contracts.

## Static assertions

- Frontmatter name/description and UI metadata parse and match the installed identity.
- Retained references resolve or explicitly identify future/manual inputs.
- Output paths, modes and statuses agree with actual consumers and templates.
- Preserve bounded authorization, concurrent edits, required independent review and human evidence.

## Test cases

### Case 1: Scoped writing

**Request / fixture:** Write two lantern-keeper lines using supplied voice and Established lore.

**Expected outcome:** Save requested narrative content without inventing a level/art pipeline; preserve canon, string IDs and supplied layout constraints.

### Case 2: Canon conflict

**Request / fixture:** Brief says founding 50 years ago; established source says 200.

**Expected outcome:** Name both sources, retain dependent text as provisional, obtain consequential canon decision and recheck final candidate; no COMPLETE canon claim.

### Case 3: Executor and output

**Request / fixture:** No target or a promised delegated file is absent.

**Expected outcome:** Return usage when target missing; absent output remains incomplete, preserve work and recover with a qualified executor.

## Evidence and grading

Record raw fixture inputs, request, actual response/artifacts, method and observed
result. Static reading, guided current-agent exercises, script execution and native
runtime dispatch are separate evidence. A fixture or expected answer alone is not
execution. Inspect useful output and failed prerequisites; rerun affected cases after
correction. Apply the shared rubric without arbitrary section or step counts.
