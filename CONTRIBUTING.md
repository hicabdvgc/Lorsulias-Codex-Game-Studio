# Contributing to This Studio

Read root/nested AGENTS.md and .codex/docs/skill-authoring.md. Identify the requirement or demonstrated
defect, inspect producers/consumers/specifications, and preserve suitable content and attribution.
Keep game configuration and unrelated edits intact. Change shared interfaces with their consumers.

Run relevant package/metadata checks and isolated behavior/helper exercises. Record actual inputs,
outputs and limitations, separating static inspection, guided exercises and native execution.
Update both catalogs when installed capabilities change, plus affected usage documentation.
Do not report plans or absent runtime evidence as passed checks. Use the repository's issue/PR
templates if an actual repository and contribution route are configured. No owner or publishing
destination is assumed. Commits, pushes and external messages follow task authorization.
