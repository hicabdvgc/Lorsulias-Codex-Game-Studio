# Narrative Rules

Cross-reference new content against relevant established lore and character voice
profiles. Record canon as Established / Provisional / Under Review with its source
and actual decision. Distinguish canon conflicts, proposals and intentional unreliable
narration. Hidden truths need definition where dependent design requires them;
intentional mysteries need not receive invented answers.

Use the actual gameplay, world and relationship rules. Preserve the developer's
consequential narrative decisions and existing authorization. Follow selected string
identity, placeholder, locale and dialogue-layout contracts; there is no universal
120-character limit or ban on idioms. Give translators context for adaptation.

Map resource-bearing text to relevant root RES_TYPE.md and TYPE_TEMP definitions.
Prose drafts, prepared string resources, recorded voice and implemented triggers
have separate evidence. Preserve concurrent edits and verify promised saved outputs.
