# Godot ui

Library baseline: **4.7.2**. Documentation checked **2026-10-08**.

## Capabilities and choices

Control nodes provide UI elements. Container parents manage their Control children’s positioning and sizing; manual child coordinates may be overwritten during layout. Use anchors for suitable simple layouts and nested containers when content-driven layout is needed.

## Application and verification

Build a menu with long localized labels and changed viewport dimensions. Inspect minimum sizes, container flags, overflow and focus. Record keyboard/controller navigation and text scaling separately from visual layout checks.
