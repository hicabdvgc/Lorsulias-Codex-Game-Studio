# Unity ui

Library baseline: **6000.6.4f1 (Unity 6.6 Update)**. Documentation checked **2026-10-08**.

## Capabilities and choices

Unity exposes UI Toolkit, uGUI and IMGUI. UI Toolkit supports runtime/editor interfaces; uGUI remains a supported GameObject-based runtime option. IMGUI is useful for editor/debug interfaces and is not recommended as the main runtime UI. Choose by required features and existing content.

## Application and verification

Compare a representative screen’s data binding, focus, input, layout and localization requirements. Check callback cleanup, hierarchy/layout costs and accessible interaction with actual evidence. Do not automatically rewrite uGUI screens.
