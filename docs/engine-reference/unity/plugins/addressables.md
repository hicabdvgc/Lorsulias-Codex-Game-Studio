# Addressables

Library baseline: **6000.6.4f1 (Unity 6.6 Update)**. Documentation checked **2026-10-08**.

## Documentation scope

Addressables 2.7.6 documentation. Confirm installed versions and compatibility separately.

## Integration

Addressables organizes assets and loads/releases them by address, with dependency management over AssetBundles. Define one owner for each acquired handle and cover success, failure, cancellation and release. Review groups, catalogs and remote/local paths from actual content needs.

## Example assessment

For a screen asset, specify when a load begins, how a late result is discarded, and who releases it after the screen closes. Inspect bundle duplication and actual memory/download evidence before claiming an improvement.
