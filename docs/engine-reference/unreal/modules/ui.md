# Unreal ui

Library baseline: **5.8.3**. Documentation checked **2026-10-08**.

## Capabilities and choices

UMG and Slate provide Unreal UI authoring/programming paths. Widget structure, data updates, display ownership and input/focus form the interface contract. Optional Common UI setup is described separately; it is not implied by use of UMG.

## Application and verification

Trace one screen through create/show/update/hide and focus restoration. Check long text, scaling, controller navigation and project-selected accessible interactions. A binary asset requires a supported inspection/editor method before claiming detailed graph findings.
