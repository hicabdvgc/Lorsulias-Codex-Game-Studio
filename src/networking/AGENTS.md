# Networking guidance

Read ../AGENTS.md and the studio root instructions. Use live technical preferences, code-root-resolution.md
and execution-and-evidence.md before dependent writes.

Use the selected authority and replication architecture. Define applicable message semantics,
validation, size/range constraints, reliability/frequency, version compatibility and lifecycle behavior.
Prediction, rollback, host migration and server authority apply only where selected or required by the
actual trust boundary. Use supplied latency/bandwidth targets and actual multi-peer evidence. Bound
sensitive logging and validate untrusted inputs. Local execution cannot prove remote/network behavior.
