Read ../AGENTS.md and the studio root instructions. Use live technical preferences, code-root-resolution.md
and execution-and-evidence.md before dependent writes.

Use relevant named-screen/HUD/pattern specifications, actual state ownership and selected input,

motion/audio routes without imposing a universal UI framework. Test relevant states, focus/navigation,
text expansion/RTL and selected resolutions on actual supported targets. Missing human evaluation or
